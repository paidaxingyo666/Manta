# Manta 的第一个发布

这是 [stablyai/orca](https://github.com/stablyai/orca) 的自建 fork 的第一个版本，
桌面端五个切片：macOS（Intel 与 Apple Silicon）、Windows、Linux（x64 与 arm64）。

## 这个 fork 改了什么

- **自建中继**。`relay-server/` 是一个可以自己部署的完整中继，手机端靠它连回不在
  同一网络的桌面端。部署时可以选一个身份共用，或者每人一个账号。
- **不强制云账号**。登录和中继默认关闭，指向你自己的部署之后才启用。
- **中文界面**，桌面端与手机端。
- **自己的发布流水线**。macOS 用自己的 Developer ID 签名并公证，Windows 不签名
  （首次安装需手动放行一次，之后应用内更新正常）。

## 从上游同步的

本版本包含上游 79 个提交，到 `v1.4.188` 为止。较大的几项：

- WSL 的每一次调用收敛到同一个 runner，21 处调用点迁移完毕
- Windows 子进程有了唯一入口，PTY 进程树用 job object 接管
- 密钥存储与应用路径改走 port，Linux 上会明确告知密钥只是混淆存储
- 终端、worktree、automations、Linear 等一批修复

## 自建版用不了的

没有后端服务，所以这些功能在本版本里是关着的：Artifacts 分享、应用内反馈提交、
插件市场。反馈请提 [GitHub issue](https://github.com/paidaxingyo666/Manta/issues)。
