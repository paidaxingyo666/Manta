# 聊天不再停在旧消息，通知不再重复弹同一条

两个一直没找对根因的老问题，这次都修好了。**桌面和手机需要一起更新**。

- **聊天停住不动**。压缩会话后 Claude 会开一个新的记录文件，而聊天还盯着旧的那个——
  界面看起来完全正常，只是永远不再更新。现在会跟着换过去。同一个原因还导致手机发出的
  消息不回显、通知反复播报同一条。
- **锁屏通知总是同一条老消息**。一批通知里显示的是最旧的那条；更要命的是消息多到超出
  长度限制时，被丢掉的恰好是最新的几条。现在保留并显示最新的。

同时跟进上游到 1.4.190：

- **SSH 远程 CLI 修好了**。启动参数两端对不上，这条路一直是断的。
- **Windows 版的原生插件构建校验**此前从未真正生效。
- 浏览器分区、agent 会话、下载目录等几处命名两端不一致，已统一。
- 上游本轮以修复为主：手机端 relay 恢复、配对重连、列表回收，以及桌面端的远程浏览器。
