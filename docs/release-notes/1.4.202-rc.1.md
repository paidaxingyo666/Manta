# 1.4.202-rc.1

Translated interfaces no longer show a stray English plural "s".

- Counts read naturally in Chinese — "3 个文件", not "3 个文件s" — across source control, uploads, checks, integrations and more
- Japanese and Korean drop the same stray suffix; Spanish and French plurals corrected where they had been left in English
- Sharing usage no longer tags an outside X account or adds a repository link, on the post or the card image
