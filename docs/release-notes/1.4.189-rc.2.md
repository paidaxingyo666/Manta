# 手机推送通了

以前手机只有打开 app 才收得到通知，因为根本没有远程推送 —— 所有通知都是运行中的
app 给自己排的本地通知。关掉 app 就没有进程，没有进程就没人排。重连时积压一次性
涌出，也是同一个原因。

- **关着 app 也会响**。桌面端发现手机没有活连接时，通过你自己的中继发一条 APNs
  推送把它叫醒。
- **不会重复打扰**。正在连着的手机已经收到了，这时不推 —— 判定延迟四秒后再做，
  因为 iOS 后台 socket 会渐进断开又自行重连，那个间隙不代表手机不在。
- **积压合并成一条**。离开一小时回来，锁屏亮一次，不是两百次。

锁屏目前显示的是通用文案而非具体内容：中继转发推送但读不到明文，要显示真实内容
需要在设备上解密，那是下一步。

## 需要中继配置

推送默认关闭。要启用，在中继上设四个环境变量并挂载 Apple 的 `.p8` 密钥，
见 `relay-server/README.md` 的「Push notifications」一节。
少设一个中继会拒绝启动，而不是悄悄不推。

## 其他

- 中继新增 `push-wake` 控制帧，复用已有的鉴权与限流；旧版中继会明确拒绝而非崩溃
- 设备推送令牌存在配对记录里，因而重启后仍在，解绑时自动清除
