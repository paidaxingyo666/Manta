# 自建三件套全部打通

这一版把「装上之后有一半功能指向不存在的服务器」这件事收尾了。

- **不再等超时**。检查更新、插件安全名单、更新提醒原来都会去请求一批不存在的
  地址，每次白等 5 到 10 秒才回到它本来就会给出的结果。更新日志现在直接从更新
  清单里读，全程零网络请求。
- **`brew install` 可用**。`brew tap paidaxingyo666/manta
  https://github.com/paidaxingyo666/Manta` 之后即可安装，发布时自动同步。
- **技能分享对自建可用**。粘贴自己服务器的分享链接、审阅、下载安装，整条链路
  打通。用 `MANTA_SKILL_PACKAGE_DOWNLOAD_ORIGINS` 指定你的存储。
- **反馈改走 GitHub issue**。填好的内容连同版本信息一起带进预填的 issue。

## 自建配置

三个环境变量，都在你指向自己的部署之后才启用：

- `MANTA_ARTIFACTS_API_URL` — 产物分享的服务端
- `MANTA_SKILL_PACKAGE_DOWNLOAD_ORIGINS` — 技能包允许的下载来源，逗号分隔
- `MANTA_FEEDBACK_API_URL` — 反馈收集端点（不设则反馈走 GitHub issue）

中继仍在 设置 → 高级 → Manta Cloud 端点 里配，服务端代码在 `relay-server/`。
