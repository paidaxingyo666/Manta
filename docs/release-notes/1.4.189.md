# 手机推送与自建三件套

第一个正式版。这一版把「装上之后有一半功能指向不存在的服务器」收尾了，并加上了
手机推送。

- **关着 app 也收得到通知**。桌面端发现手机没有活连接时，通过你自己的中继发一条
  推送。锁屏显示的是通知的真实内容——正文由桌面端加密、由手机上的扩展解开，中继
  全程读不到明文。
- **不再等超时**。检查更新、插件安全名单、更新提醒原来都会请求一批不存在的地址，
  每次白等 5 到 10 秒。更新日志现在直接从更新清单里读，零网络请求。
- **`brew install` 可用**，发布时自动同步版本。
- **技能分享对自建可用**。粘贴自己服务器的链接、审阅、下载安装，整条链路打通。
- **反馈改走 GitHub issue**，填好的内容连同版本信息一起带过去。

## 自建配置

全部默认关闭，指向你自己的部署之后才启用。

| 变量 | 用途 |
| --- | --- |
| `MANTA_ARTIFACTS_API_URL` | 产物分享的服务端 |
| `MANTA_SKILL_PACKAGE_DOWNLOAD_ORIGINS` | 技能包允许的下载来源，逗号分隔 |
| `MANTA_FEEDBACK_API_URL` | 反馈收集端点（不设则走 GitHub issue） |

中继在 设置 → 高级 → Manta Cloud 端点 里配，服务端代码在 `relay-server/`。

**推送需要中继侧额外配置**：四个 APNs 环境变量加一个密钥文件，见
`relay-server/README.md` 的「Push notifications」一节。少设一个中继会拒绝启动，
而不是悄悄不推。

## 修好的

- 应用内文档链接、帮助菜单、隐私说明原先指向不存在的域名
- 无头 Linux 部署文档里的下载命令原先必然 404
- 更新卡片不再显示 Markdown 语法，也不再从半个字上截断
- 产物分享的账号令牌只能发往运营者配置的主机
- 技能分享链接不再要求来自特定域名

## 已知限制

推送仅限 iOS。安卓的离线推送在各家厂商之间不统一，境内也用不了 Google 的通道，
需要分别集成，暂未支持。
