# 子代理不再顶掉窗格的会话

一个 agent 拉起另一个 agent 做子任务时（比如让 codex 帮忙审代码），子进程会继承
父窗格的身份。原本已经拦住了"改写窗格显示的是哪个 agent"，但**会话**这一项走的
是另一条通路，没被拦住——于是聊天被挪到子代理自己的记录上。

现在两项一起护住，并且是把窗格原本的会话结转过去，而不是清空。清空会让下一次
就失守，也会让窗格再也无法跟随会话滚动。

另外：iOS 外部测试的分发不再需要手动填写测试信息。

**已知未覆盖**：如果子代理是在父任务结束之后才被拉起，这道拦截当时并未生效。
要关掉这一半，需要一个在收到上报的那一刻可信的"这个窗格归谁"的判据，目前还没有
——现有的几个信号要么永不失效、要么会被子代理自己污染。
